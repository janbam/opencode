# Bun API Replacements for Node.js Migration

> Generated by GPT-5 with web search (2025-01-13)
> Source: Current Node.js 22+ best practices

## Overview

This document provides drop-in replacements for all Bun-specific APIs used in opencode. Assumes Node.js 22 LTS or newer.

---

## 1. File Operations: `Bun.file()` and `Bun.write()`

### Replacement: `node:fs/promises`

**Best replacement:**
- Reading, writing, existence: `node:fs/promises` (`readFile`, `writeFile`, `access`)
- If you need Blob-like interface: `fs.openAsBlob(path)` (stable in Node 22.17+)

**Gotchas:**
- There's no `fs.promises.exists`; use `fs.promises.access` or `fs.stat` wrapped in try/catch
- `writeFile` handles strings, Buffers, typed arrays, and AsyncIterable/Stream, but not Response directly

**Example:**
```typescript
import { readFile, writeFile, access } from 'node:fs/promises';
import { constants as fsc } from 'node:fs';

async function exists(path: string): Promise<boolean> {
  try {
    await access(path, fsc.F_OK);
    return true;
  } catch {
    return false;
  }
}

const filepath = 'file.txt';

if (await exists(filepath)) {
  const content = await readFile(filepath, 'utf8');
  await writeFile('copy.txt', content);
}

// Blob-like (optional, Node 22.17+)
import { openAsBlob } from 'node:fs';
const blob = await openAsBlob(filepath);
const text = await blob.text();
```

**Migration pattern:**
```typescript
// Bun
const file = Bun.file(filepath);
if (await file.exists()) { ... }
const content = await file.text();
await Bun.write(filepath, content);

// Node
import { access, readFile, writeFile } from 'node:fs/promises';
import { constants as fsconstants } from 'node:fs';

try { await access(filepath, fsconstants.F_OK); /* exists */ } catch {}
const content = await readFile(filepath, 'utf8');
await writeFile(filepath, content);
```

## 2. Process Spawning: `Bun.spawn()`

### Replacement: `execa` (npm package)

**Best replacement:**
- `execa` for simple, cross-platform, promise-based process execution
- Native alternative: `node:child_process.spawn` (zero deps, manual buffering)

**Gotchas:**
- Bun.spawn's `proc.exited` is a Promise; execa returns a Promise that resolves with `{stdout, stderr, exitCode}`
- Node's spawn returns an EventEmitter, not a Promise

**Example (execa):**
```typescript
import { execa } from 'execa';

const { stdout, exitCode } = await execa({ cwd: '/path', env: { ...process.env } })`git status`;
console.log(exitCode, stdout);
```

**Migration pattern:**
```typescript
// Bun
const proc = Bun.spawn({
  cmd: ['git', 'status'],
  cwd: '/path',
  stdout: 'pipe',
  stderr: 'pipe',
  stdin: 'inherit',
  env: { ...process.env }
});
const code = await proc.exited;
const output = await readableStreamToText(proc.stdout);

// Node (execa)
import { execa } from 'execa';
const { stdout, exitCode } = await execa({ cwd: '/path', env: { ...process.env } })`git status`;
```

## 3. Glob Pattern Matching: `Bun.Glob`

### Replacement: `glob` + `minimatch` (npm packages)

**Best replacement:**
- `glob` package (maintained by @isaacs) - supports async iteration, streams, and Glob class
- `minimatch` for matching a single path against a pattern

**Gotchas:**
- Pattern semantics are shell-style (forward slashes recommended across platforms)
- For single-string "does this path match?" checks, use `minimatch(pattern, path)`

**Example:**
```typescript
import { Glob } from 'glob';
import { minimatch } from 'minimatch';

// Scanning
const g = new Glob('**/*', { cwd: dir });
for await (const file of g) {
  // ...
}

// Matching single file
if (minimatch(file, pattern)) {
  // matched
}
```

**Migration pattern:**
```typescript
// Bun
const glob = new Bun.Glob("**/*");
for await (const file of glob.scan({ cwd: dir })) { ... }
if (new Bun.Glob(pattern).match(file)) { ... }

// Node
import { Glob } from 'glob';
import { minimatch } from 'minimatch';
for await (const file of new Glob('**/*', { cwd: dir })) { ... }
if (minimatch(file, pattern)) { ... }
```

## 4. Finding Executables: `Bun.which()`

### Replacement: `which` (npm package)

**Best replacement:**
- `which` package - supports async, sync, and custom PATH

**Gotchas:**
- Returns `null` if not found when you pass `{ nothrow: true }`; otherwise throws
- This maps well to `Bun.which` returning `null` when not found

**Example:**
```typescript
import which from 'which';

const gofmt = await which('gofmt', { nothrow: true });
if (gofmt) { /* ... */ }

const gopls = await which('gopls', { path: customPath, nothrow: true });
```

## 5. HTTP Server: `Bun.serve()` with Hono

### Replacement: `@hono/node-server`

**Best replacement:**
- `@hono/node-server`'s `serve()` for Hono on Node.js
- Same `app.fetch` shape; options for port, hostname, HTTPS, etc.

**Gotchas:**
- Node has several timeouts (`requestTimeout`, `headersTimeout`, `keepAliveTimeout`) with different defaults than Bun
- If using `idleTimeout: 0` in Bun, explicitly tune Node's server timeouts
- Returns a Node `http.Server` instance

**Example:**
```typescript
import { Hono } from 'hono';
import { serve } from '@hono/node-server';

const app = new Hono();
app.get('/', c => c.text('Hello'));

const server = serve({
  fetch: app.fetch,
  port: opts.port,
  hostname: opts.hostname
});

// Adjust timeouts if needed:
// server.requestTimeout = 0; // beware DoS implications
```

**Migration pattern:**
```typescript
// Bun
const server = Bun.serve({
  port: opts.port,
  hostname: opts.hostname,
  idleTimeout: 0,
  fetch: app().fetch,
});

// Node
import { serve } from '@hono/node-server';
const server = serve({
  fetch: app().fetch,
  port: opts.port,
  hostname: opts.hostname
});
```

## 6. Shell Template Tag: `$ from "bun"`

### Replacement: `execa`'s `$` tag

**Best replacement:**
- `execa`'s `$` tag for template-literal commands with safe interpolation
- Alternative: `zx` for scripting-oriented tool with `.text()` method

**Gotchas:**
- In execa, result is an object with `stdout` property rather than `.text()` method
- Both allow `$\`mkdir -p ${dir}\`` and `$\`git describe --tags\``

**Example:**
```typescript
import { $ } from 'execa';

await $`git describe --tags`;
await $`mkdir -p ${dir}`;
const { stdout } = await $`command`;
```

## 7. Stream Utilities: `readableStreamToText`

### Replacement: `node:stream/consumers`

**Best replacement:**
- `text(stream)` from `node:stream/consumers`
- Works with both Node streams and WHATWG ReadableStream
- Alternative: `new Response(webReadable).text()` for Web streams

**Gotchas:**
- `child_process.spawn` in Node returns Node streams (not Web streams)
- `consumers.text()` accepts either, no conversion needed

**Example:**
```typescript
import { text as streamToText } from 'node:stream/consumers';
import { spawn } from 'node:child_process';

const proc = spawn('git', ['status'], { cwd: '/path', stdio: ['inherit', 'pipe', 'pipe'] });
const output = await streamToText(proc.stdout!);
```

## 8. Module Resolution: `Bun.resolve()`

### Replacement: `import.meta.resolve()` or `createRequire`

**Best replacement:**
- ESM: `import.meta.resolve(specifier)` when resolving relative to current module (stable in Node 22+)
- For custom base ("parent"): Use `module.createRequire(baseFile).resolve(specifier)`
- Alternative: `import-meta-resolve` package for pure ESM custom parent resolution

**Gotchas:**
- Node's `import.meta.resolve`'s second parent argument is still behind a flag
- Prefer `createRequire(...)` or `import-meta-resolve` for custom base resolution

**Examples:**

ESM (relative to current module):
```typescript
const url = await import.meta.resolve('typescript/lib/tsserver.js');
```

Resolve from an arbitrary cwd via createRequire:
```typescript
import { createRequire } from 'node:module';
import path from 'node:path';

const requireFromCwd = createRequire(path.join(app.path.cwd, 'noop.js'));
const tsserver = requireFromCwd.resolve('typescript/lib/tsserver.js');
```

With import-meta-resolve:
```typescript
import { resolve as resolveWithParent } from 'import-meta-resolve';
import { pathToFileURL } from 'node:url';

const tsserverURL = await resolveWithParent(
  'typescript/lib/tsserver.js',
  pathToFileURL(app.path.cwd + '/').href
);
```

## 9. URL Utilities: `Bun.fileURLToPath()`

### Replacement: `node:url`

**Best replacement:**
- `url.fileURLToPath` from `node:url` (built-in)

**Gotchas:**
- Provide a `file:` URL; returns platform-specific path (handles percent-decoding properly)

**Example:**
```typescript
import { fileURLToPath } from 'node:url';

const path = fileURLToPath(new URL('file:///C:/path/example.txt'));
```

## Summary: New Dependencies Required

| Package | Purpose | Notes |
|---------|---------|-------|
| `execa` | Process spawning + shell template | Replaces `Bun.spawn` and `$` |
| `glob` | Glob pattern scanning | Replaces `Bun.Glob.scan()` |
| `minimatch` | Glob pattern matching | Replaces `Bun.Glob.match()` |
| `which` | Find executables | Replaces `Bun.which()` |
| `@hono/node-server` | HTTP server for Hono | Replaces `Bun.serve()` |

## Built-in Node.js Replacements (No Dependencies)

| Bun API | Node.js Built-in |
|---------|------------------|
| `Bun.file()` / `Bun.write()` | `node:fs/promises` |
| `readableStreamToText` | `node:stream/consumers` |
| `Bun.resolve()` | `import.meta.resolve()` or `createRequire` |
| `Bun.fileURLToPath()` | `node:url` |
